# Tailtriage invariant proof registry

This registry owns stable semantic contracts and classifies their executable proof boundaries.
Adjacent `TT-TEST` comments identify exact proof owners. Suspects produced by Tailtriage
remain evidence-ranked triage leads, not proof of root cause.

## Linkage contract

Every registry invariant requires at least one adjacent concrete test classified as `TT-TEST: <ID> primary`; materially distinct retained boundaries may use `secondary`. Every repository-owned Rust and Python test is classified, and ordinary support tests use `TT-TEST: support`. P03 is the sole command-owned exception: its primary proof-boundary command is canonical, and it neither requires nor permits a primary test marker.

## Distinct proof boundaries

Meaningfully independent boundaries remain distinct: arithmetic units and complete serialized
Report goldens; core validation, CLI process policy, and analyzer permissive behavior;
deterministic native/tracing equivalence and live recorder behavior; direct-package APIs and
facade features; parser, CLI/file, and teaching JSONL consumers; deterministic corpus and
runtime-sensitive operational validation; and release preflight execution versus repository and
release mutation policy.
