# Analyzer design ledger and evidence-unit charter

This is the maintainer ledger for analyzer rules: it classifies each current rule, names its
source owner, and records whether the 0.4 design preserves, replaces, or later calibrates it. It
does **not** change behavior, endorse current numbers as final 0.4 values, or turn evidence-ranked
suspects into proof of root cause.

## Ownership and reading rules

- Rust source and focused tests are factual truth. The [behavior reference](../diagnostics.md)
  owns the complete current mechanics; this ledger deliberately does not become a second formula
  reference.
- The [analyzer rationale](analyzer-rationale.md) owns rationale, provenance, and revision
  criteria. “No dedicated rationale” below means the value is source/test-owned; it does not
  invite invented historical intent.
- The [invariant proof matrix](INVARIANT_PROOF_MATRIX.md) owns A01–A13 and their executable proof
  boundaries. This ledger only cross-references them.
- The option inventory authority is `options/registry.rs::OPTION_ENTRIES`; defaults and validation
  are owned jointly by that registry and `options/mod.rs::AnalyzeOptions::validate`.
- Each row has exactly one **primary class**. A row may mention effects in other phases without
  acquiring another classification. “Public behavior/report contract” means observable analyzer
  behavior, not a supported tuning knob.

select thresholds. A representation basis, a raw event count, and a family-relevant support count
are different facts.
